# 🎵 MacBook CD 黑胶唱片播放器 — 产品方案

> 将闲置老 MacBook 改造为专属 CD 唱片播放器，插入 CD 即自动识别、获取封面与曲目，以网易云音乐经典黑胶复古界面沉浸播放。

---

## 一、产品定位与愿景

### 1.1 产品定位
**一台专属的实体 CD 唱片机**：将老旧 MacBook（带内置/外接光驱）改造为一台"开盖即用"的复古黑胶唱片播放器，让实体 CD 重获新生。

### 1.2 核心价值
| 维度 | 描述 |
|------|------|
| 🎯 极简体验 | 开机自动进入播放器，零操作门槛 |
| 💿 实体回归 | 重新拥抱 CD 实体唱片的仪式感 |
| 🎨 视觉沉浸 | 网易云经典黑胶转盘 + 唱针动画，极致复古美学 |
| 🌐 智能识别 | 自动获取 CD 封面、专辑信息、完整曲目列表 |

### 1.3 目标用户
- 家中有闲置老 MacBook（2012 年前带光驱的机型，或配备外置 USB 光驱）的用户
- CD 唱片收藏爱好者，希望用简单方式播放实体 CD
- 追求复古美学与仪式感的音乐爱好者

---

## 二、系统架构概览

### 2.1 技术选型

| 技术 | 选择 | 理由 |
|------|------|------|
| **应用框架** | Electron | 跨平台桌面应用，Web 技术实现复杂 UI 动画，社区成熟 |
| **CD 检测** | diskutil + NSWorkspace 通知 | macOS 原生支持，无需额外依赖 |
| **DiscID 计算** | libdiscid（C 库 Node 桥接） | MusicBrainz 官方推荐，精准匹配 CD 元数据 |
| **元数据获取** | MusicBrainz API | 免费开放、数据最全的音乐元数据库 |
| **封面获取** | Cover Art Archive | MusicBrainz 官方封面数据库，免费无限制 |
| **音频播放** | HTML5 Audio API + 系统 CD 播放 | 利用 macOS 内置的 CD 播放能力 |
| **UI 动画** | CSS3 + Canvas/SVG | 实现黑胶转盘旋转、唱针摆动等复古动效 |

---

## 三、核心功能模块

### 3.1 开机自启与 Kiosk 模式
- macOS 自动登录 + Login Items 自启动
- Electron Kiosk 模式全屏，隐藏 Dock 和菜单栏
- 提供 setup.sh 一键配置脚本

### 3.2 CD 检测与元数据获取
- diskutil 监听 CD 插入/弹出
- libdiscid 计算 Disc ID
- MusicBrainz API 查询专辑/曲目信息
- Cover Art Archive 获取封面图片
- 离线降级：通用封面 + Track N

### 3.3 复古黑胶播放界面
- 网易云经典黑胶风格：唱片旋转 + 唱针摆动
- 横屏布局：左唱片右曲目列表
- 深色木纹质感背景 + 暖金配色
- 核心动画：旋转、唱针、反光、封面光晕、CD 插入

### 3.4 播放控制
- 播放/暂停/上一曲/下一曲
- 进度条拖拽
- 音量控制
- 键盘快捷键支持

---

## 四、用户体验流程

### 4.1 首次使用
运行 setup.sh → 自动配置 → 重启 → 进入播放器 → 插入 CD

### 4.2 日常使用
开盖/开机 → 自动进入 → 插入 CD → 自动识别播放 → 弹出 CD → 待机

### 4.3 键盘快捷键
- Space: 播放/暂停
- →/←: 切歌
- ↑/↓: 音量
- E: 弹出 CD
- Esc(长按3秒): 退出 Kiosk
